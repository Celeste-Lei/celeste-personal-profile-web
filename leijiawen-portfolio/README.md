# 雷佳雯｜个人主页

## 本地打开
解压 ZIP 后双击 `index.html`。网站不依赖服务器、在线字体或外部脚本。

## 文件目录
- `index.html` 首页
- `about.html` 关于我
- `projects.html` 项目与作品
- `skills.html` 技能与经历
- `achievements.html` 成果与证明
- `contact.html` 联系我
- `css/style.css` 共用样式与响应式布局
- `js/script.js` 导航、显现动画、证明轮播及图片放大
- `images/` 用户提供的证明材料图片

## 资料说明
页面内容依据用户提供的简历填写稿及图片整理。简历中标注待核实或待补充的奖项没有作为已确认荣誉呈现；证明材料中无法仅凭图片确定的条目标注为“待补充”。联系方式来自简历。
